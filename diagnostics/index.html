Run the harvester

Lists every curatorial department from /departments, then every object id per department from /objects?departmentIds=N. Records already on disk are read from the cache and only new ids hit the API, through one shared rate limiter — unless refetch from live API is ticked, in which case every id is fetched again and the cache is overwritten; updated since asks the Met only for objects changed since a date and refetches those. Ids the Met answers with 404 are marked .missing and never asked for again, so Stop and Start again resumes. Tick nothing to harvest everything (about 480k objects, roughly seven hours at 20 requests/s). Start with a small limit per department to see what comes back.

Perseus accession matches

  
Compares Perseus objects whose institution is the Met (from the Perseus staging TTL) against accession numbers in the cache, with whitespace and case ignored, the same rule met_entity_resolution.py uses. Matches are also counted per department, which shows whether Perseus's Met objects all sit in Greek and Roman Art or spill into others.

Works for any id in any department, cached or not.
